# Project Constitution Template

Use this file to define repo-specific non-negotiable rules.

## Security

- Define secret handling rules.
- Define authentication/authorization requirements.
- Define input validation and logging redaction rules.

## Code Quality

- Define required type-check, lint, and test gates.
- Define rules for suppressions/exceptions.

## Architecture

- Define module boundaries and dependency direction rules.
- Define what must remain framework/domain agnostic.

## Data Safety

- Define environment separation and destructive-command policy.
- Define migration and rollback safety requirements.

## Stack

- Define primary languages, frameworks, and runtime constraints.
- Define any repo/workspace-specific toolchain boundaries.
