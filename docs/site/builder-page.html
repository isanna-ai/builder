Autonomous Execution

Autonomy with an outside judge.

Once explicitly enabled for a repo, the dispatcher drives each spec through plan, implementation, and verification. Reviewers remain separate from the author. Most importantly, the agent does not award itself a pass: the host runs the declared commands, reads their exit codes, and inspects the real diff.

Flight Record

A roadmap that cannot be flattered.

The Record is a static, read-only flight recorder and planner over your spec trees. The Planner makes blocked dependencies loud. The Run Record preserves exactly two visual registers: what the agent claimed, and what the host verified. Percent-done moves only on host-observed events.

The Planner: status, dependencies, critical path, blocked work
The Run Record: claim register and host register
No buttons, no server, no agent-authored progress math
